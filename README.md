**Cook Master - צד שרת
**
**1. תיאור הפרויקט
**Cook Master היא פלטפורמה שמאפשרת למשתמשים להירשם ולהשתתף בסדנאות בישול מגוונות. 
המערכת תומכת בניהול משתמשים, הצגת מידע על הסדנאות, והרשמה לסדנאות עם בדיקות זמינות.
צד השרת נבנה באמצעות Flask ומשתמש במסד הנתונים MongoDB.

**2. מבנה העבודה - סדר פעולות
1. אימות והרשמת משתמשים
   - משתמשים יכולים להירשם ולהתחבר באמצעות המערכת.
   - הנתונים נשמרים במסד הנתונים באופן מאובטח.

2. ניהול סדנאות
   - המערכת מציגה סדנאות שונות עם תמונות ותיאור.
   - משתמשים יכולים להירשם לסדנאות ולקבל אישור בהתאם לזמינות.

3. חיבור למסד הנתונים
   - העבודה מבוססת על MongoDB, וכל הנתונים נשלפים או נכתבים לבסיס הנתונים באמצעות שאילתות מתאימות.

4. ניתוב הבקשות (Routing)
   - Flask מנהל את כל הבקשות שמגיעות מצד הלקוח.
   - יש ניתובים לכל דף במערכת (דף ראשי, התחברות, הרשמה, סדנאות וכו').
